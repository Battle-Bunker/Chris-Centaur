## Open instrument items

Gaps in what can be measured at all. Each names what would close it, and
several are deliberately *not* CL7 items because closing them would change
the decision path.

### DETECTOR-FLIP

A3 section 4.2 item 5 asks every emission to carry {policy, detectors:{sliderPresent, ownTrail, promotionImminent}, profile}. No production producer emits it, so the DETECTOR flip rate — the quantity A3's hysteresis signal is actually about — cannot be computed from a committed batch.

*Workaround:* bin/ingest.js emits a PAIRED OUTCOME flip rate and labels it as a proxy.
*Closed by:* not CL7. It needs a detector-state field on the emission path, which is a decision-path change and outside a telemetry-only stage.

### EDGE-EV-EATS

CENTAUR_EDGE_EV's primary mechanism metric is uncontested-meals-staged by contest class. The harness records deaths and health, not staged eats split that way.

*Workaround:* mine the replay's per-turn food events; the data is in the committed replays.
*Closed by:* a miner in tools/learnloop, or a harness counter. Neither is a decision-path change.

### COHORT-COUNTERS

The arch/s2 cohort governor publishes no counter the mechanism report can fold, so P6's null is engagement-unverified by construction.

*Closed by:* arch/s2 adding its own report and CL7's mechanismReportOf folding it, after that branch merges.

### ENV-SEAM

ports.env reaches the wire policy, the worker count and the WASM default. It does NOT reach the five search-side flags or the two candidate knobs, which read process.env directly. An env-injecting caller therefore runs a different arm from the one it thinks it set.

*Impact:* None on the sim harness, which sets process-level environment per bundle. It is a trap for any in-process paired arm.
*Closed by:* threading ports.env into flaggedKnobs() and the five *Enabled() helpers — which changes which arm an env-injecting caller runs, so it is a behaviour change and not a CL7 item.
