Sets a target the bot is REWARDED for approaching. It is a weighted vote in the same scoring matrix every other heuristic feeds — never a path override — so survival heuristics can still outvote it and the snake will never die for a target. The optimal step scores the full bonus, fading to nothing at twice the best path length.
