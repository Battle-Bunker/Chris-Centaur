A binding is a row in config_store, resolved most-specific first: bot.game.<gameId> → bot.centaur.<centaurId> → bot.default → the shipped bot. These routes are read-only on purpose — an endpoint that could re-bind a live game's objective function from an unauthenticated GET is not a thing this server owns — so this panel writes the exact statement for you and then reads back whether it took. See docs/BOT-BINDING.md.

⚠ Refused bindings — these are NOT in effect

A refused binding is rejected whole and the lookup falls through to the next level, so the game plays something else and says nothing.
