# A/B: head `d4c0886` vs `stable/one-engine-lens-v2`

Sanity check requested by the owner: is HEAD at least as good as the stable
checkpoint `stable/one-engine-lens-v2`, per board class, never pooled across
board classes.

## Method

Two worktrees, each built with `npx tsc -p .`:

* **base** = `stable/one-engine-lens-v2`
* **head** = `d4c0886` (this branch)

`node dist/tests/local-game.js <scenario> 30 <seed> --nodes --json=<file>` for
`scenario` in `mixed, snakes, sparse, potions` and `seed` in `1, 2, 3` — the
deterministic node-budget mode, so a delta is signal, not machine load.
Compared with `node scripts/ab-compare.js <base files> <head files>` per board
class (never pooled; the script's own grouping already refuses to pool board
classes or opponents). All 24 runs (12 base + 12 head) completed cleanly — no
crashes, no unmatched seeds, no budget-mode mismatch warnings.

### Non-mirror comparison: not run

`grep -c opponent src/tests/local-game.ts` is **0** in the baseline worktree
and **38** in head — the baseline's runner predates `--opponent` entirely, so
it cannot be told to play `material-only` or any other profile. Per the task's
own fallback for this exact case, **only the mirror comparison is reported
below.** Generating head-only `--opponent=material-only` runs would have
nothing on the baseline side to pair against (`ab-compare.js` pairs by
scenario, seed *and* opponent), so that data would not answer "vs baseline"
at all — it was not generated.

### A schema gap, not a behavioural zero

Head's JSON summaries carry five counters baseline's schema does not have at
all: `entrapmentEpisodes`, `fatalEntrapments`, `escapedEntrapments`,
`recklessPickups`, `profitableSafePickups` (and their `Per100` rates). These
are new instrumentation from the entrapment-repair work landed on this branch
(see `docs/design/entrapment.md`). `ab-compare.js` reads a missing field as
`undefined → 0`, so "mean A" for these rows below is **not** "zero rate in
baseline" — it is "baseline never counted this." They are reported as
head-only context, not as an A/B delta, and are excluded from each board's
verdict.

## Overall

No board class shows a consistent regression on deaths, the metric the sanity
check is centered on. `snakes` and `potions` show a clear, seed-consistent
improvement in deaths (and, on `potions`, in reversals and dithers too);
`mixed` is flat on deaths with a consistent reversal-rate improvement;
`sparse` is unchanged. HEAD is at least as good as
`stable/one-engine-lens-v2` on every board class measured under mirror
self-play; the non-mirror check could not be run because the baseline build
predates the `--opponent` flag.
