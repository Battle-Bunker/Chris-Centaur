## 3. THE ONE GENUINE DRIFT: profiles have no home in the manifest

A CPP (`time-cpp-spec.md`) is an addressed, fitted, provenance-carrying
DATA member that several ECONOMY members read — but it is not a strategy:
it composes with nothing, its "law" is refuse-to-compose, and it must
join the CONFIG coordinate so verdicts under different profiles never
compare silently. `StrategyEntry.priors`/`cost` are per-member and
private; a CPP is SHARED. Proposal to the composition lens: a `PROFILE`
entry class (id, fingerprint, provenance, strata schema; compose =
refuse; readable by any member that declares it in its ReadSet), living
in the manifest so the reachability law covers it — an unfitted profile
nothing reads is deleted like any other member. The alternative
(duplicate the fit into each reader's `priors`) recreates the five-copies
disease the manifest exists to kill. This is the join's one real finding;
everything else slotted cleanly.
