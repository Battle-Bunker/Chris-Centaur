X-4 · “how sure is the bot?” — the one sentence that must not read as confidence

The rail already draws the WIDTH (⌈w⌉ and the band). The question an operator is actually asking is whether the order is proved, which is the margin to #2 read against that width — two numbers that are both on screen and never in one sentence. On the harness turn the margin is 0.0 and the width is 72.8: the bot has not proved the order at all, and nothing says so.
